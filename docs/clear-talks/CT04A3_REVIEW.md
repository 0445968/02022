## Implementation
- New server-only `lib/services/staff-invitations.ts` requires all three flags CT_STAFF_ACCESS_V2_ENABLED, CT_STAFF_ADMIN_MUTATIONS_ENABLED, CT_STAFF_INVITATIONS_ENABLED and disabled DEV_AUTH_BYPASS. New flag defaults false in .env.example. Management uses fresh cookie-bound auth.getUser, confirmed nonanonymous identity, live team.invite and independent database owner check. Redemption requires verified user, not prior staff status; database rechecks actual email/token/role/expiry and atomic membership creation. No caller actor/email/role/expiry in redeem command.
- `app/api/newsroom/team/invitations/route.ts` GET masked pagination, POST issue/replace/cancel/redeem. Same-origin JSON, actual streamed byte cap 4096 even without Content-Length, strict finite command fields, no-store/private/referrer headers and generic redacted errors. No service key or raw SQL errors exposed; generated 256-bit code returned only following successful authorized issue/replace. DB stores digest only. No mail, no SMTP, no storage of plaintext codes, no automatic retry of uncertain write. List does not retrieve raw email/token.
- `StaffInvitationManager.tsx` integrated in existing Team & Access page only after server owner check. EN/ES, current configured nonowner presets with newsroom.access and explicit revision selection, employee/contractor/freelancer type, expiry 1–7 days and nonemployee contract <=365 days, reason and explicit confirmation, masked list/status/pagination, cancel and replace, re-enter exact original email for replacement. Copy-once displayed private code in component state only, with hide button; no email sent, no automatic delivery claim. Existing UI/font tokens preserved.
- `/[locale]/staff-invite` redemption page, EN/ES, noindex/no-referrer/private/no-store; sign-in uses fixed internal return URL, account creation uses current public sign-up and manual return after verification. Verified users enter code into a masked field; POST only, no query or fragment token, no browser persistent storage. Success shows Newsroom link. No automatic author/byline linkage, no new Auth admin creation and no privilege escalation on ordinary sign-up.
- Five Node tests in `tests/ct04a-invitation-ui.test.mjs` cover actual request body bounds, malformed/foreign origin, strict commands/digests, server authority and UI secrecy contracts. No new SQL migration in this slice.
